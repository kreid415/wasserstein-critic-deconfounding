\hd{Abstract}{200 words; 7 sentences}
\begin{enumerate}[leftmargin=1.5em]
\item Adversarial batch correction trains an encoder against a discriminator predicting each cell's batch; a Wasserstein-1 (W1) critic, estimating the earth mover's distance between batches, is an alternative.
\item Question: does swapping the Jensen--Shannon (JS) discriminator for a W1 critic change biology kept at equal batch removal in scVI (single-cell variational inference)?
\item Pre-registered comparison, eight tasks of the single-cell integration benchmark (scIB): scVI plus JS discriminator, three W1 critics (reference, pooled, barycenter), maximum mean discrepancy (MMD) or Sinkhorn divergence; decoder with or without batch label.
\item \res{biology at matched batch removal, reference critic minus discriminator, per decoder.}
\item \res{trade-off area, collapse rate, local versus global removal, good-strength range.}
\item \res{divergence versus regularisation and update steps; placement against plain scVI, Harmony, Scanorama, sysVI, scANVI at equal tries, including whether any adversary beats plain scVI.}
\item \res{one-sentence guidance for scVI users.} Code and checksums: \tbd{repository address and version tag at submission}.
\end{enumerate}

\hd{Introduction}{850 words; 8 paragraphs}
\pp{Intro-1}{Batch effects are technical differences between samples that have to be removed without removing biology.}
\begin{itemize}
\item Causes: lab conditions, reagent lots, personnel, instruments, time, pipeline; mislead if correlated with outcome \citep{leek2010tackling,yu2024assessing}.
\item Single-cell RNA sequencing (scRNA-seq): replicates differ markedly \citep{tung2017batch}; persists, new modelling challenges \citep{goh2022batch}.
\item Under- and over-correction both harm \citep{yu2024assessing}; score batch removal and biology conserved \citep{luecken2022benchmarking}.
\end{itemize}
\pp{Intro-2}{Adversarial integration trains the encoder to defeat a second network that predicts the batch from each cell's latent code.}
\begin{itemize}
\item Adversary predicts batch or another confounder, e.g.\ age \citep{ganin2016domain,dincer2020adversarial}.
\item Discriminator (original generative adversarial network, GAN): JS divergence \citep{goodfellow2014generative}.
\item W1 critic: earth mover's distance, slope at most one \citep{arjovsky2017wasserstein}; Wasserstein GAN with gradient penalty (WGAN-GP) enforces it softly \citep{gulrajani2017improved}.
\end{itemize}
\pp{Intro-3}{Theory favours W1 in some settings, but its assumptions do not transfer automatically to batch correction.}
\begin{itemize}
\item W1 continuous, differentiable almost everywhere under regularity conditions, JS not; disjoint parallel lines: JS constant, W1 equals offset \citep{arjovsky2017wasserstein}.
\item Perfect discriminator, disjoint supports: vanishing gradients \citep{arjovsky2017towards}.
\item Assumes fixed real distribution, moving generator, near-optimal discriminator; here all batches move, one discriminator step per encoder step: exploratory premise check.
\end{itemize}
\pp{Intro-4}{Aligning batches exactly can cost accuracy when batches contain different cell-type proportions.}
\begin{itemize}
\item Unequal label proportions: classifier error grows with tighter alignment \citep{zhao2019learning}; exact alignment leaves error at least the proportion gap \citep{wu2019domain}.
\item sysVI study: adversarial conditional variational autoencoder, adversarial multi-omics method mixed unrelated cell types under imbalance, more at higher strength \citep{hrovatin2025integrating}.
\item Imbalance changed clustering, annotation, differential expression, mapping, trajectories in five methods \citep{maan2024characterizing}; compare at equal batch removal.
\end{itemize}
\pp{Intro-5}{In image GANs, differences between losses shrink once each loss is tuned equally.}
\begin{itemize}
\item Enough tuning and restarts: most losses similar, none consistently beat non-saturating GAN loss \citep{lucic2018gans}.
\item Spectral normalisation helped consistently, gradient penalty sometimes \citep{kurach2019large}.
\item So a critic--discriminator difference may reflect regularisation, update budget or tuning: inference from image studies, tested by follow-up.
\end{itemize}
\pp{Intro-6}{Several single-cell methods already use adversarial or Wasserstein-type alignment, mostly with a reference batch and a custom backbone.}
\begin{itemize}
\item Reference batch: iDLC, WGAN-GP critic plus Sinkhorn term \citep{jiang2026geometric}; scStarCorrect, aligns all batches to one reference (from abstract only) \citep{gu2025scstarcorrect}.
\item Wasserstein critics: Beaconet, one per batch, no reference \citep{xu2024beaconet}; IMGG, WGAN-GP generator, synthetic target \citep{wang2022imgg}; ResPAN, mutual nearest neighbours \citep{wang2022respan}; IMAAE, anchor batch, known labels \citep{wang2023integrating}.
\item Standard-GAN discriminators: Portal, clamped logits \citep{zhao2022adversarial}; AIF, plus batch classifier \citep{monnier2024novel}; ABC, label-using branches \citep{danino2024batch}.
\item Li et al.: MMD or adversarial mutual-information penalty on preliminary scVI, Pareto trade-off \citep{li2022trade}.
\end{itemize}
\pp{Intro-7}{No study we found compares JS, W1 and MMD or optimal-transport (OT) objectives on one stock scVI backbone.}
\begin{itemize}
\item Closest: six batch losses in one scVI framework; no W1, OT or explicit MMD \citep{yi2025benchmarking}.
\item Nearest designs: Li et al.\ \citep{li2022trade}; iDLC, no JS or MMD \citep{jiang2026geometric}. W1 critics, reference anchoring, MMD to a reference exist \citep{shen2018wasserstein,wang2021imap,amodio2019exploring,shaham2017removal}.
\item Absence is search-based, not exhaustive: state databases, terms. \tbd{repeat the search before submission}
\end{itemize}
\pp{Intro-8}{We report a pre-registered comparison at matched batch removal, built to answer four questions.}
\begin{itemize}
\item Contribution: JS, three W1 critics, MMD, Sinkhorn on stock scVI, matched removal, eight tasks; guidance allows that no adversary beats plain scVI; follow-up on divergence versus regularisation and update steps.
\item Questions: (i) premise check: batches nearly separable; discriminator gradients vanish early, critic's persist (exploratory)? (ii) Equal removal: different biology; more local? (iii) Good-strength width; divergence, regularisation or steps? (iv) Any adversary beats plain scVI; placement against tools?
\item Scope: scVI at defaults; architecture, warm-up not varied.
\end{itemize}

\hd{Methods}{about 2,800 words; 18 paragraphs}
\pp{Meth-1}{Every method is added to one stock scVI model at its default settings, with two decoder versions.}
\begin{itemize}
\item scVI \citep{lopez2018deep}, scvi-tools \citep{gayoso2022python}: 10 latent dimensions, 128 hidden units, zero-inflated negative binomial; scvi-tools epoch rule; epochs, minibatch, latent size equal within task.
\item Conditioned decoder gets batch label (usual use); unconditioned does not, so adversary is sole correction. Separate primary result each.
\item Plain scVI: strength zero; scored on posterior mean.
\end{itemize}
\pp{Meth-2}{Each method adds a penalty, weighted by a fixed strength, to the scVI loss (Table 1).}
\begin{itemize}
\item Discriminator: scvi-tools fool loss, JS-type \citep{goodfellow2014generative}, one step. W1 critics \citep{arjovsky2017wasserstein}: five steps, gradient penalty 10 \citep{gulrajani2017improved}; reference (each batch against reference), pooled (against all others), barycenter (against minibatch Wasserstein barycenter, an average distribution \citep{cuturi2014fast}).
\item Reference batch: highest cell-type entropy (uses labels).
\item No network: MMD, multi-scale Gaussian kernel \citep{gretton2012kernel}; debiased Sinkhorn divergence, entropy-regularised OT \citep{cuturi2013sinkhorn,genevay2018learning,feydy2019interpolating}, not W1 at this smoothing. Reference: scvi-tools adversarial classifier (conditioned only).
\end{itemize}
\pp{Meth-3}{Training settings and the adversary input are the scvi-tools defaults, with a few declared differences between methods.}
\begin{itemize}
\item Adversary reads the posterior mean, with no per-dimension standardisation. Both defaults were kept after two pre-registered pilots (two tasks, both decoders, three seeds): a posterior sample as input (three adversarial methods) and standardisation (five methods) each lowered bio conservation at matched batch removal slightly (mean change $-0.004$ and $-0.003$; 9 of 12 and 14 of 20 task--decoder--method combinations evaluable) and met none of the criteria for switching.
\item Steps differ by design: one discriminator, five critic.
\item Kullback--Leibler (KL) warm-up 400 epochs: incomplete on four shorter tasks, penalty acts from step one. Non-finite loss or latent: failed fit, counted.
\end{itemize}
\pp{Meth-4}{The tasks are eight integration tasks of the single-cell integration benchmark (scIB), used as distributed.}
\begin{itemize}
\item Six real (pancreas, lung, immune, human--mouse immune, gene-activity small and large chromatin-accessibility (ATAC)), two simulations \citep{luecken2022benchmarking}; no new data.
\item Four families: pancreas, lung, immune (two), ATAC (two); simulations per task, never pooled.
\item 2,000 highly variable genes; counts as distributed (18 batches, four tasks, non-integer).
\end{itemize}
\pp{Meth-5}{Each fit is scored with scIB metrics, unscaled, on all cells.}
\begin{itemize}
\item Batch score: mean of principal-component regression, batch average silhouette width (ASW), graph integration local inverse Simpson's index (iLISI), graph connectivity, k-nearest-neighbour batch-effect test (kBET) \citep{buttner2019test}.
\item Biology score: mean of task's biology metrics.
\item Raw 0--1; selection score 0.4 batch + 0.6 biology.
\end{itemize}
\pp{Meth-6}{A pilot on three tasks gave each penalty family its own strength range for each decoder, because strength has a different scale for each penalty.}
\begin{itemize}
\item It fitted plain scVI and the six penalties at ten strengths from 0.1 to 3,000 on small chromatin-accessibility (ATAC), immune and simulation 1 tasks, both decoders, seeds 100--102 (1,098 fits); where a range reached the edge of that grid, two further strengths were fitted (36 fits), which is why two ranges below end at 0.03 and 10,000.
\item Six strengths from this half-decade grid cover a range that runs from the largest strength at which every pilot task still shows no effect to the strength at which every task has over-corrected (batch removal stops rising) or collapsed (a fit fails, or biology falls 0.10 or more below plain scVI); where that span holds fewer than six grid values, the next values above (then below) are added.
\item Chosen ranges (conditioned, unconditioned decoder): discriminator 0.1--30, 0.03--10; the three critics 0.1--300, 0.3--100; maximum mean discrepancy (MMD) 3--3,000, 3--1,000; Sinkhorn divergence 0.3--10,000, 0.3--300.
\item Supplement: the noise threshold for no effect, the six strengths of each range, extra fits at grid edges, Sinkhorn pilot refitted after a solver correction.
\end{itemize}
\pp{Meth-7}{The main benchmark fits each penalty at the six strengths its family received in the pilot, on all eight tasks, to ask whether a reference critic keeps different biology than a discriminator at equal batch removal.}
\begin{itemize}
\item It uses both decoders and seeds 0--4: plain scVI (80 fits), the scvi-tools adversarial classifier (40 fits, conditioned decoder only) and six penalties at six strengths (480 fits each), 3,000 fits in all.
\item The pilot rules were frozen on 4 October 2026, before the pilot reported here was run; their amendments and the main-benchmark analysis were frozen on 16 October 2026, before anyone read a main-benchmark score (19 fits had been scored but not read), and the analysis is run once; the follow-up rule was registered before any follow-up fit was scored.
\item Supplement: registration dates and amendment, early-scored fits, grid-edge extension fits, deviations.
\end{itemize}
\pp{Meth-8}{Methods are compared at the same amount of batch removal, not at the same penalty strength.}
\begin{itemize}
\item Equal strength is not equal correction: scales differ and biology trades off against batch removal, so biology is compared at one batch score.
\item The matched level $b^*$ lies halfway between plain scVI's mean batch score and the highest mean batch score all six penalties reach at strengths with no failed fit, for each task and decoder.
\item A task and decoder pair is low-signal if that gap is under 0.02, because $b^*$ then cannot be placed reliably; such pairs are reported separately. In the pilot, immune and simulation 1 with the conditioned decoder were low-signal (gaps 0.019, 0.007).
\end{itemize}
\pp{Meth-9}{The primary comparison reads biology at $b^*$ for the reference critic and the discriminator, with trade-off area as a second view.}
\begin{itemize}
\item Each method's curve joins plain scVI and its six strengths by their mean batch and biology scores; biology at $b^*$ is read where the curve first reaches $b^*$, interpolating between neighbouring strengths.
\item The result is the reference critic's reading minus the discriminator's, per task and decoder, with uncertainty from repeating the reading with each of the five seeds left out; a task is not evaluable if it is low-signal, either curve never reaches $b^*$, or fewer than four of the five readings exist.
\item The trade-off area uses all six points rather than one reading: it is the area of the batch-score by biology-score plane that a method's points reach beyond a corner at plain scVI's batch score and 0.10 below its biology score, divided by the batch gap that sets $b^*$ so that tasks can be compared.
\end{itemize}
\pp{Meth-10}{Collapse rate and local versus global removal add two further views of the same comparison.}
\begin{itemize}
\item A penalty that sometimes ruins the embedding is hard to use even when its best fit is good, so a fit counts as collapsed if it fails or its biology score is at least 0.10 below the same seed's plain scVI.
\item The collapse rate (collapsed share of 30 fits per method, task and decoder) has Clopper--Pearson intervals \citep{clopper1934use} (exact binomial 95\% intervals); the reference critic's rate minus the discriminator's is pooled with a margin of 5 percentage points.
\item Two methods can reach one batch score by different routes. Local removal averages three neighbourhood metrics (integration local inverse Simpson's index, k-nearest-neighbour batch-effect test, graph connectivity); global removal averages two whole-embedding metrics (principal-component regression, batch average silhouette width).
\item The batch score is $(3\,\mathrm{local}+2\,\mathrm{global})/5$, so at $b^*$ more local removal means less global; the question is whether the reference critic reaches $b^*$ with more local mixing than the discriminator, tested at the primary comparison's crossing with an exact sign test over real tasks and the pooled model.
\end{itemize}
\pp{Meth-11}{Results from the six real tasks are pooled in one model, and a rank test is reported as description only.}
\begin{itemize}
\item The model weights each task by its uncertainty and lets related tasks share a family effect (all immune cells are in the human--mouse immune task, and small ATAC cells are in the large ATAC task); simulations and low-signal pairs are never pooled.
\item A direction is declared if the posterior probability (the model's probability given the data) is at least 0.95 that the overall difference lies beyond the margin of 0.01 (the smallest biology-score difference counted as real) on one side; practical equivalence if it is at least 0.95 that the difference lies within $\pm0.01$; otherwise the result is inconclusive \citep{corani2017statistical}.
\item A descriptive Wilcoxon signed-rank test, with Holm's correction over the six primary results (comparison, area and collapse rate, each per decoder), cannot reject with six tasks: its smallest $p$, 0.031, exceeds the first threshold $0.05/6=0.0083$.
\item From the pilot (the matched-strength contrast on its six task and decoder pairs), the design is underpowered: the minimal detectable effect at 80\% power is 0.131 over six real tasks (0.182 over four dataset families), power for a difference of 0.02 is 0.104 over six real tasks, and equivalence within $\pm0.02$ cannot be shown.
\item Supplement: model priors, sensitivity analyses.
\end{itemize}
\pp{Meth-12}{The width of each method's range of good strengths shows how closely a user must tune it.}
\begin{itemize}
\item Quality is the selection score, 0.4 times the batch score plus 0.6 times the biology score (the scIB overall weights, unscaled), so it does not depend on which methods are compared.
\item For each method, task and decoder, the best strength has the highest mean selection score over five seeds; the good range holds every strength whose mean is at least the lower end of the best strength's 95\% confidence interval, and its width is the span from smallest to largest strength in decades (factors of ten).
\item The width is descriptive, with no decision rule.
\end{itemize}
\pp{Meth-13}{Single-strength tables and equal numbers of tries place each penalty against plain scVI and standard tools.}
\begin{itemize}
\item These ask whether any adversary improves on plain scVI, and how the penalties compare with Harmony \citep{korsunsky2019fast}, Scanorama \citep{hie2019efficient}, sysVI \citep{hrovatin2025integrating}, scANVI (which uses cell-type labels; \citealp{xu2021probabilistic}) and principal-component analysis (PCA), the uncorrected reference.
\item Harmony, Scanorama and sysVI are run at six settings each, scANVI and PCA at one, with seeds 0--4 for the neural methods and one run otherwise (408 fits with sensitivity settings).
\item In the single-strength tables each penalty uses a strength not tuned on that task: the strength with the best mean selection score on real tasks of other families (related tasks never choose for each other), shown beside the task's own best strength as an optimistic bound.
\item The equal-tries comparison gives each method the expected best selection score among $k$ settings drawn at random, $k=1$--6, so methods with more settings gain no advantage; it is optimistic, because the best setting is chosen and scored on the same data, and scANVI has its own stratum.
\item Both are descriptive.
\end{itemize}
\pp{Meth-14}{A follow-up experiment tests whether the divergence, rather than the regularisation, optimiser or update steps that also distinguish a critic from a discriminator, explains any gap.}
\begin{itemize}
\item It uses small ATAC, immune and pancreas tasks, both decoders and seeds 10--12, with three strengths per setting (the matched strength of its base method in the main benchmark, meaning the one whose batch score is nearest $b^*$, and its two grid neighbours), so it runs only after the main benchmark is scored: nine settings, 486 fits.
\item At one adversary step, the discriminator runs plain, with spectral normalisation \citep{miyato2018spectral} (each layer rescaled so its output cannot change steeply), with an R1 gradient penalty \citep{mescheder2018training} (penalising the output's slope at the cells), and with spectral normalisation plus the critic's optimiser (the critics' Adam settings: learning rate $10^{-4}$, betas 0 and 0.9); the pooled critic runs with gradient penalty at 1, 5 and 10 steps and with spectral normalisation at 1 and 5 steps.
\item The follow-up uses the pooled critic, not the reference critic of the primary comparison.
\item Supplement: R1 weight, no gradient penalty on spectrally normalised critics, incomplete factorial design, failure counts instead of collapse rates (the follow-up has no plain-scVI fits).
\end{itemize}
\pp{Meth-15}{One follow-up contrast is confirmatory, and a fixed rule says when the divergence explains the main gap.}
\begin{itemize}
\item Per decoder, the contrast is the spectrally normalised pooled critic minus the spectrally normalised discriminator with the critic's optimiser, both at one step, which differ only in the loss and its target.
\item Biology is read at $b^*$ by interpolating along the three strengths where they bracket $b^*$ (unlike the primary comparison, with no plain-scVI starting point, and all three leave-one-seed-out readings required); otherwise the task is not evaluable. For every task the difference at the matched strengths is also reported, labelled fixed-strength. The 0.01 margin and 0.95 rule are as in the main analysis; Holm's correction covers the two results of the companion test, which cannot reject with three tasks (smallest $p$ 0.25).
\item The divergence is said to explain the main gap only if the primary comparison has a declared direction for that decoder, the contrast has the same direction, and every regularisation and step-count contrast is smaller in size.
\item Supplement: no direction can be declared with fewer than three evaluable tasks.
\end{itemize}
\pp{Meth-16}{A planned pre-check will adjust the strengths of the two arms of the confirmatory contrast.}
\begin{itemize}
\item The discriminator arm inherits the plain discriminator's strengths although its learning rate is ten times lower, and the pooled-critic arm inherits the five-step critic's strengths and was never piloted, so either may never reach $b^*$ and the contrast could not be read.
\item The pre-check has not been run; it will fit 36 models, 18 per arm, on small ATAC, immune and simulation 1 with both decoders, seed 100, at the three strengths the pilot gave the base method.
\item The rule was fixed before any pre-check fit: for each arm, of the four task and decoder pairs not low-signal in the pilot, if at least three of those pairs stay below $b^*$ at all three strengths, its strengths move one step up the half-decade sequence (\ldots, 0.03, 0.1, 0.3, 1, 3, \ldots); if at least three stay above $b^*$ at all three, one step down; otherwise they stay, with no second pre-check.
\item \res{outcome for each arm (strengths moved up, moved down or kept), to be filled here once the pre-check is run.}
\end{itemize}
\pp{Meth-17}{An exploratory premise check asks how separable batches are and how adversary gradients behave in training.}
\begin{itemize}
\item Theory predicts vanishing discriminator gradients when batches are perfectly separable \citep{arjovsky2017towards}; the check asks whether batches are nearly separable before integration and whether the discriminator's gradient vanishes early while the critics' persist.
\item It needs no new fits: separability uses the 80 plain-scVI embeddings (8 tasks, 2 decoders, 5 seeds) and gradients use the per-epoch training logs of the 2,880 fits of the six penalties, with no strengths or seeds selected.
\item A 15-nearest-neighbour classifier predicts each cell's batch (five-fold cross-validation); separability is the area under the receiver operating characteristic curve (AUC; 0.5 is chance, 1 is perfect) averaged over batches, and batches count as nearly separable if it is at least 0.95 in all five seeds of a task and decoder.
\item Each epoch logs the adversary's gradient norm (the penalty's gradient with respect to the embedding, before multiplying by strength) and, for the discriminator, its accuracy at naming each cell's batch; a gradient vanishes early if it stays at or below 10\% of its own peak from within the first 10\% of epochs.
\item The result is descriptive, with no pooled test and no claim about whether the premise holds.
\end{itemize}
\pp{Meth-18}{An exploratory label-transfer check asks whether cell types learned in some batches are recovered in a held-out batch.}
\begin{itemize}
\item Label transfer tests a downstream use of the embedding, annotating a new batch from the others, at matched batch removal.
\item It needs no new fits: it uses the embeddings of each method at its matched strength (nearest $b^*$ in batch score, never chosen by label-transfer accuracy) for five seeds, plus plain scVI and the scvi-tools adversarial classifier, labelled unmatched.
\item Each batch is held out in turn and a 15-nearest-neighbour classifier trained on the others predicts its cell types; cell types found in only one batch are dropped, a choice made from the labels alone.
\item F1 (the harmonic mean of precision and recall) is computed per cell type and averaged over types, with the gap between each matched batch score and $b^*$ printed beside it; there is no test or decision rule, and low-signal pairs are tabulated but left out of summaries.
\end{itemize}

\pp{Disc-4}{The design limits what the data can show.}
\begin{itemize}
\item Underpowered (minimal detectable effect 0.131, six real tasks, 80\% power); Wilcoxon descriptive. Four families, two nested pairs (human--mouse immune contains all immune cells; large ATAC contains small).
\item Strength grids set on three of eight tasks. Reference critic five steps, discriminator one; update-step control only for pooled critic.
\item One batch variable per task; ATAC as gene-activity matrices; non-integer counts as distributed; scoring includes training cells; Sinkhorn not W1; reference choice uses labels.
\end{itemize}
\pp{Disc-5}{Several factors are outside the scope of this comparison.}
\begin{itemize}
\item Not varied or tested: architecture, KL warm-up (incomplete on shorter tasks, penalty from start), reference batch, batch number; composition shift read from strength curves, not a dose-response test. Adversary steps reuse one minibatch.
\end{itemize}

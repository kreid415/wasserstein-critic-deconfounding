## Raw dataset sources

- scIB integration task files: Luecken et al. (Nature Methods 2022) "Benchmarking atlas-level data integration in single-cell genomics", figshare article 12420968, version 8 (`https://figshare.com/ndownloader/articles/12420968/versions/8`, as named in `README.md`). Files used (names from `configs/dataset_registry.json`): `human_pancreas_norm_complexBatch.h5ad`, `Immune_ALL_human.h5ad`, `Immune_ALL_hum_mou.h5ad`, `Lung_atlas_public.h5ad`, `sim1_1_norm.h5ad`, `sim2_norm.h5ad`, `large_atac_gene_activity.h5ad`, `small_atac_gene_activity.h5ad`. `cluster/jhpce/stage_scib.sh` expects a sources table `file, figshare_file_id, url, bytes, md5` (8 rows); that table is not in the repo, so rebuild it from the figshare article page and check md5 against the figshare listing.
- GEO accessions (GSE86469, GSE81608, GSE94820, GSE130148) appear in `scripts/prep_scib_task.py` only as provenance for batches that were repaired or dropped; the scripts do not download them. GSE194122, GSE132044, GSE118767, GSE96583 appear in `docs/PAPER_PLAN.md` as datasets dropped under SI-02.
- Software sources: kBET from GitHub (above); PyTorch wheels from download.pytorch.org.

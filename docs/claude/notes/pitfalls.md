# Pitfalls, dead ends and tool gotchas

Each bullet ends with its memory row id and evidence tag (observed / stated / inferred). Tags: **[C]** still applies; **[H]** historical (July to September 2026 setup, kept so the mistake is not repeated). Terms: SLURM = the cluster job scheduler; OMP = OpenMP threading; h5ad = AnnData file; Lustre = shared cluster file system; E1, E2, E4, E9 = the July 2026 revision experiments (see experiment-history.md).

## Counting and completeness

- **[C]** A result CSV's mere existence does not mean the config finished: heavy-dataset tasks write per seed, so a file may hold 1 of 3 seeds. Count rows per design or arm (target 3 seeds each) and confirm the rows carry real metric values; check logs for `Wrote N rows`, and that none says `Wrote 0 rows`. [mem_a561c654a1c5 · observed; mem_42d75895b3bc · observed; mem_581569fb1972 · observed]
- **[C]** Never take an expected config count from a remembered or registry figure. E4, E1 and E8 counts scale with the number of batches; read the harness-recorded `n_batches` column. Using lung's cell-type count (16) as its batch count produced a phantom gap and 14 doomed jobs that all crashed with `KeyError: 'ref_design'`. [mem_edb8777acec2 · observed; mem_a1be44213db6 · observed; mem_fea42a1aa312 · observed]
- **[C]** A filter value that is not in the harness grid selects zero configs silently. Verify each requested value exists in the grid before launching, and after launch confirm no task logs zero rows. [mem_581569fb1972 · observed]
- **[C]** Merging split result files: drop duplicates on the natural key before counting (resume or re-run appends rows). Keys: E1 [dataset, method, d_coef, seed]; E4 [dataset, ref_design, seed]; E9 [dataset, _arm, seed] with `_arm` = 'discriminator' when method is 'discriminator', else the formulation column. [mem_3a6f32ab92a4 · observed; mem_4de3cea65f89 · observed]
- **[C]** When many SLURM tasks append to one CSV, give each task its own output file (race-free), then merge after completion. [mem_b29b7303e6be · observed]
- **[C]** E5 outputs sit in per-dataset subdirectories (`results/E5nb/<dataset>/*.csv`); a non-recursive glob wrongly reports them missing. [mem_436e2042dca1 · observed]
- **[C]** Silent dropping hid incomplete waves earlier; failed configs must leave a NaN row with a `failed` flag (see verified-code-facts.md). A claim that tasks "walled with zero rows" was wrong once: an empty log meant the tasks never started (still pending in a throttled array). Check queue state before blaming a timeout. [mem_30c3f99deb13 · observed; mem_32fc04275aee · observed]
- **[A]** `run_reference.py` (E4 harness) has a latent crash: its post-sweep summary `fixed = df[df["ref_design"].str.startswith("fixed_ref")]` (now line 121) raises `KeyError: 'ref_design'` when the data frame is empty, because an empty frame has no columns. Any `--ref-design-only <tag>` that matches no design (for example a `fixed_refN` beyond the dataset's batch count) filters everything out and kills the task. Harden the summary block; whether a guard was added after July was not checked. [mem_3ef1e3195a5a · observed]
- **[C]** `sinfo -o %F` prints Allocated/Idle/Other/Total; the second field is idle. An earlier claim of "11 idle A100 nodes" was really 5 idle (11 allocated), and "0 pending" was stated without running `squeue`. Read pending jobs from `squeue` before describing queue depth. [mem_53e6fe2660e7 · observed]

## Cost and runtime estimates

- **[C]** Calibrate a cost estimate on at least one full production-setting run (150 epochs plus the full scIB metric suite). An estimate scaled from a 30-epoch diagnostic was 6 to 7 times too low per config and 25 times too low in total (6896 CPU-hours true vs 272 quoted). [mem_6510af7fede2 · observed; mem_13ef95426e5b · observed]
- **[H]** Measured runtime model on a 16-core cluster CPU node: t(hours) = 1.05e-07 x n_cells^1.69 (pancreas 1.4 h, lung 3.7 h, immune 3.6 h anchors; atac_small 0.75, sim1 0.84, sim2 1.86, atac_large 22.7, immune_hum_mou 28.9 h per discriminator config; critic runs about 2.5 times more). The exponent above 1 arises because the metric suite (LISI, silhouette, kNN graph) dominates, not training. Recompute from a measurement rather than reusing a stored total (the 4-point lambda sweep was quoted 350 CPU-hours, truly 559). Superseded for the current programme by `docs/WALL_TIME.md` and `docs/cost_model_per_fit.csv`. [mem_c97dbe6d6cb2 · observed; mem_88ccb940e374 · observed; mem_83dfdd5ff0fb · observed]
- **[C]** One SLURM task = one config. Bundling several configs in one task (an E2 task of 8 backbones x 3 seeds) guarantees a timeout on real datasets; 547 of 552 tasks hit a self-imposed 12 h wall. Partition limits were 3 days: set walls from measured runtime with headroom (48 h for a longest task of about 11.8 h). [mem_e6bc4196e9fe · observed; mem_13ef95426e5b · observed; mem_a05d3699ad05 · observed; mem_6d04674d4dee · observed]
- **[H]** On the two heavy datasets (atac_large 85k cells, immune_hum_mou 98k cells) the real time sink was data prep (highly variable genes plus PCA, 30 to 45 min per task, repeated by every task) and file-system contention: about 14 tasks reading the 4.0 GB h5ad at once from shared Lustre stalled for hours (a lone read takes about 13 s). Throttle such arrays to low concurrency (about 4). Monolithic multi-config harnesses (E4: about 12 designs; E9: 4 arms) timed out even on a 4 h GPU wall; split them one task per design or arm. [mem_660a61d09103 · observed; mem_a886ff1cb462 · observed; mem_10c444a8330c · observed; mem_304710ca2224 · inferred]
- **[H]** Subsampling the heavy datasets was considered and not used; full cell counts were kept (no subsampling footnote needed for that wave). [mem_13c0b2de4982 · observed]

## Environment and tooling

- **[C]** Local pytest or torch aborts with `OMP: Error #179 pthread_setaffinity_np failed` unless threads are guarded: `KMP_AFFINITY=disabled OMP_NUM_THREADS=1 NUMBA_NUM_THREADS=1 MKL_THREADING_LAYER=SEQUENTIAL python -m pytest tests/ -q` (use `OMP_NUM_THREADS=8` for GPU smoke tests). [mem_427fe5806bfa · observed; mem_f381820accfb · observed]
- **[C]** scikit-learn's `LogisticRegression` no longer accepts `multi_class`; construct it as `LogisticRegression(max_iter=1000)`. [mem_51ebf1fa1d2f · observed]
- **[C]** Grepping `.ipynb` files for short patterns is unreliable (embedded base64 images produce huge false hits); parse the JSON and scan only code-cell `source` lines. [mem_fb0c842a1c95 · observed]
- **[C]** Compute-node `/tmp` is not shared with the login node: helper scripts referenced from an `sbatch` body must live in the repo or on shared storage. Write batch scripts with conda activation as `source $(conda info --base)/etc/profile.d/conda.sh; conda activate <env path>`, not `source activate`. [mem_58373c13be08 · observed; mem_7afeaa4ac884 · observed]
- **[C]** Do not move files by printing base64 to a terminal: stdout is capped and the middle is elided, so decoding fails. Copy files with scp, rsync or git, and verify checksums. [mem_1fd49efc28fb · observed; mem_e93fef166370 · observed]
- **[H]** `set -eo pipefail` in a cluster status-check job exits 1 on grep-no-match or a busy `sacct`; guard each command in a status probe. A cluster login node can stop responding for minutes under load (Rockfish, DSAI); jobs already on compute nodes keep running, so wait and retry instead of resubmitting. [mem_972f9518dee4 · observed; mem_70a50730ade2 · observed; mem_28c68ea3fc96 · observed]
- **[H]** The pancreas data had to be moved in pieces because a transfer tool capped single files at 256 MB; the local copy's md5 was recorded when cached. [mem_d6ebbe8af036 · observed]

## Analysis and figure traps

- **[C]** Figure fidelity: never let per-panel free y-axes magnify a no-effect dataset into apparent structure (a lung panel's +/-0.001 noise became a visible curve). Use a shared y-axis across comparable panels and give no-effect datasets a separate, labelled panel. [mem_bc806d1c913e · observed]
- **[C]** Cell-type probe lift is non-monotonic in lambda_adv (dips at 0.05 in 10 of 12 dataset-by-head arms, then recovers); unexplained. Do not build an argument on that axis. [mem_f02cfa764771 · observed]
- **[H]** A convergence trace on the conditioned NB backbone is not evidence that 150 epochs suffices for the unconditioned models, and a loss plateau does not imply a metric plateau. A valid convergence test uses independent full runs at 150, 300 and 450 epochs (not a checkpoint-along-the-way script, which resets Adam state at each checkpoint). [mem_ab9614dacb7f · observed; mem_0d043ccaa588 · observed; mem_d6ebbe8af036 · observed]
- **[H]** Dead end: the "native-backbone" models (July 2026) did not learn cell-type structure (ARI about 0.001, asw_celltype 0.492 to 0.500, NMI 0.005 to 0.08; the submitted scCRAFT-era pancreas discriminator had ARI 0.931), so the "reversals" first reported (E2 trade-off narrower; E5 biology reversed) were differences between two degenerate models, not findings. [mem_e6f94fa5423c · observed; mem_dc4da8fdab82 · observed; mem_2524c83cf5f8 · observed]
- **[H]** Provisional results written before that diagnosis (mem_dc4da8fdab82, mem_2524c83cf5f8, mem_67d467a14bc1, mem_d6f2179c3d8b) are superseded by mem_e6f94fa5423c; do not cite their effect sizes. [mem_d6f2179c3d8b · observed; mem_67d467a14bc1 · observed]

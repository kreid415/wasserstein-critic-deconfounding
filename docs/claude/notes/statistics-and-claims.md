# Statistics and what may be claimed

Each bullet ends with its memory row id and evidence tag. Terms: p-value = probability of data at least as extreme under the null; n = number of independent units; Nadeau-Bengio (NB) = the corrected resampled t-test for overlapping cross-validation folds; CV = cross-validation; ICC = intra-class correlation; delta = critic minus discriminator; lift = probe accuracy minus the majority-class baseline.

Standing rules in `CONSTRAINTS.md` (e.g. SI-xx entries on pseudo-replication, blinding, seeds) are authoritative; this file records the reasoning that came from the memory rows. Numbers below are from the July to September 2026 unconditioned-backbone wave, which used a harness later found defective (counts bug C2, code audit 2026-10-01); they illustrate the statistical point and must not be cited as results.

## Pseudo-replication: the unit is the dataset

- The earlier headline (critic removes more residual batch signal; mean delta in linear batch lift -0.0427, t = -3.22, p = 0.004, n = 24) counted 24 dataset-by-backbone pairs as independent, but the 4 backbones ran on the same 6 datasets. Datasets are the independent unit; backbones are repeated measures. **Never report p = 0.004.** [mem_6eb5dcdf165f · observed; mem_aff813ce96b8 · observed]
- Honest analyses at n = 6 datasets: dataset-level t-test p = 0.0878; Wilcoxon p = 0.1562; 4 of 6 datasets favour the critic (the two that do not, lung and sim1, have no baseline batch effect to remove). A mixed model `delta ~ 1 + (1|dataset)` gave p = 0.0342 with ICC = 0.397 but a boundary convergence warning at 6 groups. Effect size is stable (-0.0427) across methods. Report n = 6 with p about 0.09 as a consistent trend, or the mixed model with its caveat. Excluding no-effect datasets is defensible only if stated up front, not applied post hoc. [mem_aff813ce96b8 · observed; mem_05aecef5b6fb · observed]
- **Never report a cluster-bootstrap p at n = 6.** A null simulation (true effect 0, n = 6, 2000 repetitions, 400 bootstrap draws each) gave a 13.1% false-positive rate at alpha = 0.05 (nominal 5%); it had returned p = 0.0030 for the E2 effect. [mem_9b3275546b2f · observed; mem_05aecef5b6fb · observed]
- The lambda-sweep contrast (critic minus discriminator batch lift -0.021, -0.032, -0.058 at lambda 0.05, 0.2, 0.5; p 0.05 to 0.07 at n = 6 datasets) is "consistent in direction", not significant. Three analyses of the same effect disagreeing is itself the finding that n = 6 is too small to separate them. [mem_c82657963b9d · observed; mem_05aecef5b6fb · observed]
- Only 3 of 6 light datasets showed a measurable batch effect in the latent at lambda_adv = 0 (linear batch lift: sim2 0.269, pancreas 0.179, atac_small 0.177; immune 0.014, lung -0.001, sim1 -0.024). On the no-effect datasets a rising discriminator batch lift means it introduces batch structure; figures must segregate them. [mem_3e7caf49a352 · observed; mem_c82657963b9d · observed]
- Adding the two heavy datasets moves n from 6 to 8 (about 541 CPU-hours) and is still underpowered; the honest framing stays per-dataset significance plus consistent direction. [mem_226d8e0481dc · observed]
- SUPERSEDED, do not cite: the earlier "statistical framing" using E2 n = 24 as the critic-vs-discriminator claim; the 2026-10-02 `PAPER_PLAN.md` replaces it with pre-registered endpoints. The code audit of 2026-10-01 found the old harness fitted the NB likelihood to log-normalised values (counts bug C2). [mem_1f205c234555 · observed]

## Nadeau-Bengio correction: what it does and does not cover

- The user's implementation is `calculate_corrected_paired_t_stats(a, b, n_folds=5, test_train_ratio=0.25)` in `notebooks/results.ipynb` (about line 1094 of the JSON), not in the `wcd` package. It matches the published formula t = mean(d) / sqrt((1/n + n_test/n_train) var(d)); ratio 0.25 implies 5 folds (ratio = 1/(k-1)). [mem_f2d88d64b3fa · observed]
- **Scope:** the correction handles overlapping training sets across CV folds of one dataset. It does not apply to an across-dataset comparison: datasets share no data and are independent by construction. CV within a dataset buys per-dataset significance (the paper's Table 1 format) but the generalisation claim stays at n = 6 (or 8). [mem_f2d88d64b3fa · observed]
- The user chose per-dataset 5-fold CV plus NB correction as the next experiment (state at the time); the open question was whether it covers NB_uncond only or also the conditioned NB. Cost: 60 runs / 233 CPU-hours (5-fold) or 36 runs / 140 CPU-hours (3-fold). Plumbing needed first: see the blockers in verified-code-facts.md. [mem_fe194ae8b541 · stated; mem_f2d88d64b3fa · observed; mem_45e1e769ed54 · observed]
- Convergence must be resolved before committing that cost; if 300 or 450 epochs change metrics versus 150, every completed number is affected and the CV cost doubles. [mem_0d043ccaa588 · observed]

[mem_e6f94fa5423c · observed; mem_2524c83cf5f8 · observed; mem_6fc4988296f7 · observed]
- Premise check: the disjoint-support premise holds across the 8 benchmark datasets (batch separability 0.68 to 1.00, chance-normalised; kNN cross-batch fraction 0.00002 to 0.17); a cross-species immune dataset (about 98k cells) is the near-disjoint control. [mem_102570692a52 · observed]

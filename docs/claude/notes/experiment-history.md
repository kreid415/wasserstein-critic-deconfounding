## 2. The scCRAFT pivot and the native-backbone rebuild

- User decision: drop scCRAFT as the reference backbone and rebuild E2 as a multi-VAE study of critic vs discriminator on VAEs "as published". Root cause: the old E2 hard-coded scCRAFT's cosine and triplet auxiliary losses onto every backbone, so aux losses could dominate and backbones were not real models. New design: batch-conditioning of the decoder (conditioned vs unconditioned) is an explicit axis, giving 8 configs (NB, ZINB and LDVAE each conditioned and unconditioned; Gaussian and Poisson unconditioned only) x 2 heads x 3 seeds. [mem_2de87e3f5a01 · stated]
- The 4 first E9 jobs and the old E9 were cancelled as obsolete (they ran on the scCRAFT default backbone); this orphaned every mechanistic experiment (E1, E4, E5, E8, E9) until a new primary backbone was chosen. [mem_fa49b87e716a · observed]
- The scCRAFT package was deleted (commit 6a2eff0); the training objective became backbone loss plus lambda_adv x adversarial loss with no triplet or cosine term; Leiden clustering was removed from `data.py`. [mem_b4e19cd53bb7 · observed]
- Epoch decision at the time: keep 150 epochs for the production wave (real-data pancreas convergence, 16382 cells / 9 batches, 300 epochs on a local GPU: loss rises slowly and monotonically, no jumps; the synthetic-data regime switch at epochs 117 to 175 was an artifact). Later judged not valid evidence for the unconditioned models (see pitfalls.md). [mem_d6ebbe8af036 · observed; mem_ab9614dacb7f · observed]
- User directive: run the full matrix (E1, E2, E4, E5, E8, E9) on all 8 datasets, superseding the 3-dataset E2 scope. E8 excludes lung and immune_hum_mou (2 batches each). Full matrix = 110 SLURM tasks: E2 64, E1 16, E4 8, E5 8, E8 6, E9 8. [mem_c999ae8cba78 · stated; mem_23911e9dbeac · observed; mem_68ef50affd5a · observed]
- NB-wave arrays: 28567576 (38 tasks, cancelled), 28703515 (110 tasks, completed about 2026-07-26 with 118 non-empty result CSVs), resume 29116204. Gaps were then closed on the two heavy datasets via a per-lambda E1 split, a GPU array 29405845 (12 tasks, 4 h wall, A100) and a CPU grind array 1972887 on the second cluster; output CSVs went to `results/{E2rb,E1nb,E4nb,E5nb,E8nb,E9nb}/`. ## 3. Structure-collapse blocker and its diagnosis (late July to August 2026)

- Blocker: the native-backbone models did not learn cell-type structure (ARI median about 0.000 to 0.001; NMI 0.005 to 0.08; asw_celltype 0.492 to 0.500; E5 purity 0.10 to 0.30 vs 0.82 to 0.97 in the scCRAFT era). The two earlier "reversals" were differences between degenerate models. Write no Discussion on those results. [mem_e6f94fa5423c · observed]
- Root cause of the mixing failure (direct probes on real pancreas): the decoder was batch-conditioned, so z carried almost no batch signal for the adversary; unconditioned backbones engage the adversary but do not fix conservation, which is a second, independent defect (missing auxiliary losses). Details in verified-code-facts.md. [mem_2bb545a9b0dc · observed; mem_3a09ce063326 · observed; mem_18721e00976e · observed]
- User decisions for the unconditioned re-run (all four given together, later confirmed as settled): add probe-based conservation metrics regardless; run all four unconditioned backbones (Gaussian, NB_uncond, ZINB_uncond, LDVAE_uncond); keep the conditioned backbones as a deliberate contrast arm; start with the 6 light datasets and gate the heavy datasets on that result. Restoring the triplet loss was left an open question. Proposed reframing ("adversarial alignment is largely redundant with decoder batch-conditioning") was not yet approved. [mem_f82ad2e1367a · stated; mem_649e1a7ed712 · stated; mem_0690a7bd3eba · stated; mem_fddc7989dcb1 · inferred]
- Cost: the two heavy datasets account for about 77% of CPU cost; the first estimate (E1+E2+E5 on 8 datasets x 4 unconditioned backbones = 688 runs / 1174 CPU-hours; 6 light datasets 516 runs / 272 CPU-hours) was later shown 25 times too low (see pitfalls.md). Full E1+E2+E4+E9+E5 on 8 datasets was estimated at 955 runs / 1679 CPU-hours. [mem_83dfdd5ff0fb · observed; mem_be46dc39753e · observed]
- Option C array 1984023 failed wholesale (547 of 552 tasks hit a 12 h wall; outputs: 5 E2u files). Replacement: array 1985963 (312 one-config tasks, 48 h wall; E2 = 6 light datasets x 8 backbones x 2 heads x 3 seeds = 288 tasks plus E5 = 24 tasks); E1 deferred. Outputs `results/E2u/`, `results/E5u/`. [mem_13ef95426e5b · observed; mem_02f1fd226dd7 · observed; mem_bbf3b92a6bac · stated]
- Sequencing convention: cheap scope first, gate heavy datasets on its result; this reversed the earlier "keep grinding" call because the substrate (not coverage) was the open question. E1 lambda sweep deferred (81% of cost), then run on NB_uncond only: array 1986963, 144 one-config tasks (6 light datasets x 2 heads x lambda {0, 0.05, 0.2, 0.5} x 3 seeds), 559 CPU-hours; output `results/E1u/`. [mem_0690a7bd3eba · stated; mem_a8d88328408f · observed; mem_88ccb940e374 · observed; mem_c82657963b9d · observed]
- E2+E5 re-run completed 312 of 312 (first valid critic-vs-discriminator comparison on unconditioned backbones, later judged pseudo-replicated; see statistics-and-claims.md). Lambda sweep completed 144 of 144. [mem_6eb5dcdf165f · observed; mem_c82657963b9d · observed]

# Claude Science file archive (historical, not authoritative)

Byte copies of files saved in the Claude Science project before the move to Claude Code (2026-10-16), one folder per save date.
They are snapshots: older copies of CONSTRAINTS.md, ANALYSIS_SPEC.md, notebook pages and handoffs are superseded by the
files at the repository root, `docs/` and `notebook/`. Never cite or follow an archived copy as the current rule or plan.
`MANIFEST.csv` lists all 522 saved files, which were copied, and why the others were not (file type or size, possible
X1/X13 blinded content by name, email addresses, confidential journal correspondence). Links of the form
`{{artifact:<id>}}` inside these files point to the old store and do not resolve.
